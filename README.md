# IP Address Finder

A lightweight web app that automatically detects the user's public IP address and displays useful information such as location, ISP, timezone, and coordinates.

## Features
- Auto-detect visitor IP
- Show country, region, city, and timezone
- Show ISP and coordinates
- Refresh button
- Mobile-friendly responsive design

## Run locally

Open `index.html` in a browser, or use a small local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Note
This app uses public IP geolocation APIs and may require internet access to work.
